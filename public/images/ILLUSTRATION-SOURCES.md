# Aset ilustrasi EKSPLORA

Dibuat khusus menggunakan built-in image_gen pada 17 November 2026. Bukan screenshot website dan tidak mengambil gambar dari situs pihak ketiga. Semua gambar berukuran 1586 x 992 piksel, dikonversi ke WebP tanpa mengubah komposisi. Sumber PNG tetap tersimpan pada direktori generated_images Codex.

UI berupa Blade/CSS; statistik tetap berasal dari database. SVG habitat lama tetap tersedia sebagai fallback dan untuk konten kuis yang sudah ada.
